# PikaPython v2.0.0-rc4 Release Announcement

PikaPython v2.0.0-rc4 publishes the latest V2 development baseline with the
LVGL Linux binding prerequisites and the completed official basic-suite
workflow. The release keeps CPython-aligned behavior, import capability, and
V2 performance and resource efficiency as the primary product goals.

## New Features and Improvements

- **LVGL Linux prerequisite baseline**: Added the common parser, VM, runtime,
  package, and binding behavior needed by the LVGL v9.5 core and Linux SDL
  workflow.
- **Import and callable behavior**: Parenthesized selective imports, aliased
  imports, imported class preservation, lambda lowering, lambda parameter
  binding, and module globals in lambdas are supported by the V2 frontend.
- **LVGL callback and driver coverage**: Linux binding metadata now covers core
  callbacks, widget metadata, object positioning, window styles, event symbols,
  animation callbacks, and the exercised display/input driver paths.
- **Bytearray and native binding behavior**: Integer construction and borrowed
  bytearray container handling follow the embedded binding contract without
  changing the official payload.
- **Official basic examples**: The selected `tests/api`, `tests/display`, and
  `tests/indev` basic slices now run from their exact official sources through
  the immutable Linux SDL workflow.

## Validation

- The V2 Linux development baseline at commit
  `bc92195be5cbc38bb609e5284a977a932995e4ee` completed the LVGL prerequisite
  stages on the fixed development environment.
- The official LVGL basic-suite work is tracked separately; its remaining
  `uasyncio_example1.py` exact-source task is still in progress and is not
  claimed as complete by this release.
- Existing V2 Linux runtime, binding, lifecycle, and Valgrind evidence remains
  the baseline for this RC. New hardware-driver claims require target-specific
  validation.
- Performance figures use matched-CPU Linux measurements. QEMU results are
  limited to functional, Flash, RAM, and recovery checks.

## Known Issues

- `examples/uasyncio_example1.py` and `lib/lv_utils.py` exact-source execution
  is not yet complete; the current release does not claim full official
  asynchronous-example compatibility.
- Thread-backed concurrency and lock APIs are not included. `eventloop` is a
  cooperative scheduler without thread support.
- Some LVGL font, PNG, filesystem, fbdev/evdev, and target-hardware driver
  examples remain `feature-disabled` or `platform-only`.
- CPython compatibility covers the documented embedded subset and bundled
  module contracts, not the complete CPython standard library.
- Generated LVGL binding class reflection metadata still needs full
  generator-side end-to-end verification; runtime fixtures alone are not a
  complete generated-binding acceptance result.

## Module Releases

The module groups and project-template workflow remain as documented in the
[previous release note](v2.0.0-rc3.md). The common template uses
`pikapython.yaml` composition and defaults `bootEntry` to `main.py`.
